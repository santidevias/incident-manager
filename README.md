# Aplicación para Gestión de Incidentes

> Aplicación web desarrollada en Angular para el registro, seguimiento y administración eficiente de incidentes.

---

## 🛠️ Stack Tecnológico Planificado

- **Framework & Core:** Angular 20, TypeScript (Strict Mode)[cite: 1]
- **Arquitectura & Estado:** Componentes Standalone, Angular Signals, RxJS[cite: 1]
- **Navegación & Seguridad:** Angular Router, Guards funcionales[cite: 1]
- **Comunicación HTTP:** HttpClient, Interceptores funcionales[cite: 1]
- **Formularios:** Reactive Forms[cite: 1]
- **Estilos & Maquetación:** HTML semántico, CSS y SCSS[cite: 1]
- **Pruebas & Calidad:** Pruebas unitarias, ESLint[cite: 1]
- **Control de Versiones:** Git[cite: 1]
- **API Mock / Backend:** Mockoon[cite: 1]

---

## 🚀 Requisitos Previos

Asegúrate de contar con las siguientes herramientas instaladas localmente antes de ejecutar el proyecto:

- [Node.js](https://nodejs.org/) (Versión recomendada según compatibilidad de Angular 20+)[cite: 1]
- [npm](https://www.npmjs.com/)[cite: 1]
- [Angular CLI](https://angular.dev/tools/cli) (Versión 20 o superior)[cite: 1]
- [Mockoon](https://mockoon.com/) (Para la simulación de servicios REST)[cite: 1]
